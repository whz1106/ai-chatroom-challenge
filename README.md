# AI 编程实操：多人 AI 聊天室

**时间：25 分钟。** 请使用你熟悉的 AI 编程工具，开发一个可以在本地运行的多人 AI 聊天室。技术栈不限，允许查阅文档。

用户可以在同一个聊天室中实时交流，也可以通过 `@助手` 向 AI 提问。AI 作为聊天室中的一个成员回复，所有用户共享聊天内容。

## 功能要求

1. **进入聊天室**：用户设置昵称后进入同一个公共聊天室，无需注册登录。消息显示发送者、正文和发送时间，AI 回复与用户消息有明确区分。
2. **实时通信**：支持至少两个用户同时在线。任意用户发送消息后，其他用户无需刷新页面即可收到。需要通过后端完成真实的网络通信。
3. **历史记录**：用户消息和 AI 回复保存到数据库。刷新页面、重新进入或重启后端后，仍能查看已保存的聊天记录。
4. **AI 助手**：发送以 `@助手` 开头的消息时，由后端调用 AI，结合最近的聊天内容生成回复，并发送给所有在线用户。普通消息不触发 AI 回复。
5. **异常处理**：空消息不能发送；AI 回复过程中有明确的等待状态；调用失败时给出反馈，普通聊天仍能继续使用。

## 开发约定

- 项目包含前端、后端和数据库，页面样式自行决定。
- AI 接口自行选择；没有可用接口时允许使用 mock，但需明确标记模拟回复。
- API Key 不得放入前端代码或提交到仓库。
- 提供必要的启动命令和配置说明。
