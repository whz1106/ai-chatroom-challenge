# AI 编程实操：多人聊天室

**时间：25 分钟。** 请使用你熟悉的 AI 编程工具完成以下任务，允许查阅文档。

## 任务一：配置项目 AI 工作环境

- 在项目中安装至少一个与本题相关的 skill，并实际使用一次。
- 在根目录编写适用于本项目的 `AGENTS.md`，声明所安装的 skill。

## 任务二：实现多人 AI 聊天室

在提供的聊天室基础项目上增加 `@助手` 功能：

- 两个独立浏览器会话能够实时互发消息。
- 用户发送 `@助手` 消息后，由后端调用提供的 AI 接口，所有在线用户都能看到回复。
- 用户消息与 AI 回复保存到数据库，刷新页面后仍能查看。
- AI 调用失败时给出反馈，普通聊天仍可正常使用。

可使用提供的 mock 接口。API Key 不得放入前端代码或提交到仓库。
